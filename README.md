# G Raion — Buenas Vibras

Sitio web oficial del proyecto musical **Buenas Vibras** de G Raion.

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

El proyecto está configurado con una ruta base relativa para facilitar su publicación en GitHub Pages.

## GitHub Pages

El workflow incluido en `.github/workflows/deploy.yml` construye y publica automáticamente el sitio en GitHub Pages cada vez que se hace push a `main`.

En el repositorio de GitHub, activa **Settings → Pages → Source: GitHub Actions**.
